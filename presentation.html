02

사용자 (User Personas & Pain Points)

👤 박현우 팀장 (대기업 HR 채용 담당자) 인사담당자
💬 "서류가 너무 많아 다 검토하기 힘드네요... 외부 인력을 써도 평가 기준이 회사와 다르고, 주관적인 느낌 대신 100% 원문 근거를 1초 만에 확인하고 싶어요."
• 핵심 니즈: 500건 서류 중 성과 근거 수재 1초 스크리닝
• 해결 가치: 검토시간 80% 절감 + 면접 질문 준비 0분
👤 이지은 지원자 (기업 취업준비생) 지원자
💬 "제 지원서가 블라인드 채용 규정에 맞게 신상 차별 없이 공정하고 일관된 직무 역량 기준으로 평가받는지 확신이 들지 않아요."
• 핵심 니즈: PII 자동 마스킹으로 공정한 블라인드 평가 보장
• 해결 가치: 주관 배제, 오직 서류 속 실제 직무 성과 근거로만 평가

시스템 설명 (System Architecture & Features)

✨ 5대 핵심 기능

  • 1. 본문 근거 하이라이터 (🟢긍정/🔴리스크 1:1 위치 매칭)
  • 2. 직무별 역량 가중치 슬라이더 (5대 역량 즉시 재정산)
  • 3. 종합 평가 대시보드 (100점 게이지 & Recharts 레이더 차트)
  • 4. 맞춤 면접 질문 키트 (약점 기반 질문 의도 추출)
  • 5. 지원자 비교 & 평가서 출력 (PDF / 1클릭 인쇄)

🏛️ 엔터프라이즈 기술 스택 (GCP Vertex AI)

• Frontend: React 18 + Vite 6 + Tailwind CSS
• Security: Express Proxy Gateway + PII Anonymizer
• AI Infrastructure: Google Cloud Vertex AI Enterprise
• Audit Trail: Google BigQuery Audit Log Integration
• Data Governance: Enterprise Zero Data Retention 준수
