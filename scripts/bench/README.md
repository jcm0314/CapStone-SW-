# 실측 벤치마크 (scripts/bench)

발표·사업계획서에 쓰는 숫자를 **직접 재현할 수 있도록** 남겨 둔 측정 스크립트입니다.
"이 숫자 어떻게 쟀어요?"라는 질문에는 이 폴더를 보여 주면 됩니다.

| 파일 | 측정 내용 | 비용 |
|---|---|---|
| `pii_bench.mjs` | 개인정보(PII) 마스킹: 카테고리별 검출률 + 개인정보가 아닌 문장을 잘못 가리는 오탐률 | 무료 (API 호출 없음) |
| `pii_holdout.mjs` | 정규식 튜닝에 **쓰지 않은** 문장으로 다시 확인 (과적합 점검용, 수정 금지) | 무료 |
| `claude_bench.mjs` | 실제 Claude 4-에이전트 평가: 건당 소요시간, 토큰, 비용, AI 인용문의 원문 일치율, 점수·판정 | **과금** (아래 참고) |
| `samples.json` | `claude_bench.mjs`에 넣는 가상 자소서 6건 | - |
| `claude_bench_result.2026-11-16.json` | 2026-11-16 실측 원본 결과 | - |

## 실행

```bash
# PII (무료)
node scripts/bench/pii_bench.mjs
node scripts/bench/pii_holdout.mjs
# 또는 npm run bench:pii

# Claude 실측 (과금) — 루트 .env 의 ANTHROPIC_API_KEY 사용
node --env-file=.env scripts/bench/claude_bench.mjs
# 또는 npm run bench:claude
```

`claude_bench.mjs`는 서버(`server/index.js`의 `handleEvaluation`)와 같은 경로로 돌립니다:
PII 마스킹 → `executeMultiAgentEvaluation`(Grounding → Critic → Supervisor ∥ Interviewer).
결과는 같은 폴더에 `claude_bench_result.<오늘날짜>.json`으로 저장됩니다.

### 비용 주의

- 모델: `claude-haiku-5-5` (서버 기본값). 단가 입력 $0.10 / 출력 $0.50 (100만 토큰당, 프롬프트 100K 이하)
- 환율은 **1,400원/$로 가정**
- 1건 ≈ 7원, 샘플 6건 전체 ≈ 45원
- `ANTHROPIC_MODEL`을 바꾸면 스크립트 안의 `PRICE` 값도 바꿔야 비용이 맞게 계산됩니다

## 한계 (발표 때 같이 말할 것)

- 샘플은 모두 **직접 만든 가상 문장**이고 규모가 작습니다 (Claude 6건, PII 68개 항목). 실제 지원서 분포를 대표하지 않습니다.
- PII 튜닝 세트 100%는 그 세트에 맞춰 고친 결과입니다. 일반화 성능은 holdout 94.4%가 더 정직한 숫자입니다.
- 정규식 방식이라 목록에 없는 학교 약칭, 문장 속에 섞인 이름(지원자명 입력과 다른 표기) 등은 놓칠 수 있습니다.
- Claude 결과(점수·소요시간)는 실행할 때마다 조금씩 달라집니다. 1회 실행 결과입니다.
