# 29. 메인 화면 디자인 개편 (밝은 테마 · 기능 탐색 중심)

- 우선순위: 후순위
- 상태: 대기
- 근거: [트러블슈팅 리포트 2026-11-12](../docs/troubleshooting/2026-11-12_user-scenario-report.md), Issue #47(카페 피드백 메모)

## 문제
현재 화면은 어두운 배경에 이모지·영문 마케팅 문구("4대 멀티에이전트 AI 서류 심사관 & B2B 멀티테넌시 RLS 플랫폼", "🤖 4-Stage Multi-Agent 앙상블 감사로그 ↗" 등)가 많아 **AI가 만든 티가 강하고**, 처음 온 사용자가 무엇을 할 수 있는지 한눈에 알기 어렵습니다. 카페 피드백(#47)에서도 "디자인적으로 신뢰성을 줄 수 있도록"이 나왔습니다.

## 방향
- **밝은 테마** 기본 (다크는 선택), 과한 이모지·그라데이션·영문 수식어 제거
- **메인(첫 화면)**: 가장 이목을 끄는 기능 하나를 크게 — "자소서를 붙여 넣으면 근거 문장이 형광펜으로 표시되는" 1:1 근거 매칭 데모를 히어로 영역에 배치
- **검색창(⌘K 커맨드 팔레트)** + **메뉴**: 기능을 상태별로 노출
  - `구현됨`: 서류 평가·형광펜 근거, 면접 질문 생성, HITL 보정, 면접관 공유 링크·메모, 지원자 비교·표절 매트릭스·Top-N, 보고서 출력, 파일 업로드, 지원자 피드백 리포트
  - `준비 중`(기획서에 있으나 미구현): 일괄 합불 통보(메일/SMS), 서류↔면접 2-Track 뷰, 태그형 가중치, 문항별 평가, ATS 연동
- 데모용 샘플 결과에는 `샘플` 배지 (26번과 연계)
