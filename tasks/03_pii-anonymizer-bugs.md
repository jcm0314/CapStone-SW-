# 03. PII 마스킹 유틸 결함 수정 (정규식 lastIndex, 성명 이스케이프)

- 우선순위: P0
- 상태: 완료

## 배경
- 대상 파일은 `src/utils/piiAnonymizer.js`입니다. README와 ISSUES #3은 "7종 PII 자동 마스킹"을 주장합니다.
- 결함 1: `REGEX_PATTERNS`가 모두 `g` 플래그를 가진 모듈 전역 객체입니다.
  - `hasPII()`가 `.test()` 결과를 short-circuit으로 반환하면 `lastIndex`가 0이 아닌 값으로 남습니다.
  - 그 다음 `hasPII()`나 `anonymizePII()` 호출에서 이메일 등을 **탐지하지 못하는 상태 누수**가 생깁니다.
- 결함 2: `new RegExp(candidateName)`이 성명을 이스케이프하지 않습니다.
  - 예: 샘플 지원자명 `정지훈 (지원자)`의 괄호가 정규식 그룹으로 해석되어 마스킹이 실패합니다.
  - 정규식 특수문자가 들어간 이름은 런타임 SyntaxError를 낼 수도 있습니다.

## 목표
- 반복 호출해도 결과가 동일하고, 어떤 이름 문자열에도 안전한 마스킹을 만듭니다.
