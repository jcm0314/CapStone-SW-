## ❓ 2. LG CSO AX 멘토 예상 Q&A & 완벽 답변 스크립트 (Top 5 Q&A)

### Q1. "기존의 ChatGPT나 일반 AI 자소서 요약 툴과 우리 프로젝트의 결정적 차이는 무엇인가요?"
> **[답변 스크립트]**  
> "시중의 단순 AI 요약 툴은 실무자 개인의 요약에만 머무르는 **'수평적 요약'**에 그쳐 C-Level이나 경영진이 AX의 효능감을 체감하지 못합니다.  
> 저희 시스템은 **① 100% 자소서 원문 근거(Grounding) 캡처 ➔ ② 서류 약점 기반 면접질문 자동 도출 ➔ ③ C-Level 서류 승인 보고서 및 BigQuery 감사 트레일**까지 **'종적(Vertical) 의사결정 파이프라인'**을 한 줄기로 관통하여 전 직급이 AX 효능감을 100% 체감할 수 있다는 점에서 결정적 차이가 있습니다."

---

### Q2. "LG그룹 사내 보안 규정이나 개인정보(PII) 유출 위험은 어떻게 대처하나요?"
> **[답변 스크립트]**  
> "클라이언트 브라우저가 외부 API 키를 직접 들지 않고, **Express 3-Tier API Gateway**를 거치도록 설계했습니다.  
> 게이트웨이 전단에서 **전화번호, 이메일, 성별, 출신학교 등의 PII 및 블라인드 채용 항목을 자동 익명화(Masking)** 선처리하며, **Zero Data Retention** 및 전사 감사 로그를 **Google BigQuery**에 암호화 보관하여 사내 보안성 심의 기준을 100% 충족합니다."

---

### Q3. "LG EXAONE 3.0이나 사내 온프레미스 LLM 도입 시 아키텍처 변경이 큰가요?"
> **[답변 스크립트]**  
> "아닙니다. 저희 백엔드 서비스 계층(`server/proxyServer.js`)은 **Multi-Agent Orchestrator 구조**로 상 абстракт화되어 있어, 환경 변수 변경만으로 **GCP Vertex AI (Gemini)에서 LG EXAONE 3.0 사내 API 또는 사내 Vector DB RAG로 코드 수정 없이 1초 라우팅 스위칭**이 가능합니다."

---

### Q4. "AI가 환각(Hallucination)으로 없는 내용을 지어내서 평가하면 어떻게 하나요?"
> **[답변 스크립트]**  
> "저희는 **0% Hallucination Assurance Protocol**을 탑재했습니다. AI가 생성한 근거 문장이 실제 지원서 본문 텍스트와 **Exact Substring/Fuzzy Jaccard 유사도 85% 미만**일 경우, 해당 평가를 즉시 무효화하고 `🟡 면접 검증 필요(Verify)` 상태로 강제 전환하도록 안전 장치를 구축했습니다."

---

### Q5. "현업 HR 담당자나 꼰대 면접관들이 AI 도입에 반발하지 않을까요?"
> **[답변 스크립트]**  
> "그 점을 최우선으로 고려하여 **Human-in-the-Loop(인간 중심 결정) 헌장**을 수립했습니다. AI는 점수를 확정하는 인사권자가 아니라 100% 근거를 캡처해 주는 보조 도구입니다. final 승인 시 면접관이 **'AI 근거를 검토하였으며 최종 합/불 판단은 면접관 본인이 수행함'** 체크박스와 전자서명을 해야만 제출되도록 하여 현업 면접관의 주도권과 수용성을 높였습니다."
